# AudioMax-DAW-Source

## Overview:

AudioMax is probably going to be a lightweight DAW (Digital Audio Workstation). Unlike FL Studio and many others, however, it has many additional features and conveniences that will be included, including interesting and experimental new features possibly supported by machine learning!
